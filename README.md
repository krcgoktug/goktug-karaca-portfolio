# Goktug Karaca Portfolio

Modern single-page portfolio website built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` directly, or serve with any static server.

## Deploy

This project is Vercel-ready as a static site.

## Quick customizations

- Replace `assets/profile-photo.jpg` with your preferred portrait.
- Update social links in `index.html` under `#contact`.
- Edit project cards in `index.html` under `#projects`.
